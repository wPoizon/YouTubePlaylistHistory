# YouTubePlaylistHistory
A python program that saves the history YouTube playlists to allow the user to see if videos within the playlists have been removed or renamed, and if so what their previous title was.

Install the prerequisites within [prerequisites.txt](prerequisites.txt), add the playlists within [config.jsonc](config.jsonc) and then run the program by running [playlist_tracker.py](playlist_tracker.py)! The playlist data is then saved within the `reports` folder.
